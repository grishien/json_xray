# JSON X-Ray — интеграция в Проводник Windows (portable)

Два `.reg`-файла для регистрации портативного `json-xray.exe` в контекстном
меню Проводника и в списке «Открыть с помощью» — без установщика и без прав
администратора (только `HKEY_CURRENT_USER`).

| Файл | Что делает |
|---|---|
| `json-xray-install.reg` | добавляет все ключи интеграции |
| `json-xray-uninstall.reg` | удаляет все добавленные ключи |

## Подготовка

1. Скопируйте портативную сборку в папку установки, например:
   `C:\Tools\json-xray\json-xray.exe`.
2. Если путь другой — откройте `json-xray-install.reg` в текстовом редакторе
   и замените все вхождения `C:\\Tools\\json-xray\\json-xray.exe` на свой путь
   (обратные слэши в `.reg` экранируются двойными: `\\`).

## Применение

- **Двойной клик** по `json-xray-install.reg` → подтвердить импорт, либо
- из терминала (права администратора не нужны):

  ```cmd
  reg import "apps\desktop\portable\json-xray-install.reg"
  ```

Изменения подхватываются Проводником почти сразу; если меню не обновилось —
перезапустите Проводник:

```cmd
taskkill /f /im explorer.exe && start explorer.exe
```

## Проверка

1. ПКМ по `.json` / `.yaml` / `.yml` / `.xml` / `.csv` файлу:
   - Windows 11: современное меню → «Открыть с помощью» → **JSON X-Ray**
     (работает благодаря ключам `OpenWithProgids`).
   - Классическое меню («Показать дополнительные параметры» / `Shift+F10`):
     пункт **Open with JSON X-Ray** с иконкой (ключи `SystemFileAssociations`).
2. ПКМ по папке → **Open with JSON X-Ray** (классическое меню).
3. Проверка ключей из терминала:

   ```cmd
   reg query "HKCU\Software\Classes\Applications\json-xray.exe" /s
   reg query "HKCU\Software\Classes\SystemFileAssociations\.json\shell\JsonXRay" /s
   reg query "HKCU\Software\Classes\.json\OpenWithProgids"
   ```

## Откат

Двойной клик по `json-xray-uninstall.reg` (или `reg import ...`), затем при
необходимости проверьте, что ключи удалены:

```cmd
reg query "HKCU\Software\Classes\Applications\json-xray.exe"
```

`reg query` вернёт ошибку «удалённый ключ не найден» — значит, очистка прошла.

## Примечания

- Ассоциации по умолчанию **не меняются**: значение `(Default)` у расширений
  не перезаписывается, добавляются только пункты «Открыть с помощью» и
  пользовательский verb контекстного меню.
- `.yaml` и `.yml` регистрируются независимо и не конфликтуют.
- Написать в реестр прямо в `HKEY_CLASSES_ROOT` без прав администратора
  нельзя, поэтому используется `HKCU\Software\Classes` — это пользовательская
  половина объединённого представления `HKCR`, Проводник видит ключи так же,
  как если бы они лежали в `HKCR`.
- В Windows 11 кастомные (классические) verb'ы показываются в меню
  «Показать дополнительные параметры»; в современном меню приложение
  доступно через «Открыть с помощью».
