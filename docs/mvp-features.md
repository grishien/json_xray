# Фичи MVP — json_xray

Зафиксировано в рамках **Фазы 1** (roadmap.md, п. 1.3). Источник требований — [roadmap.md](../roadmap.md).
Продукт: Tauri-приложение для визуализации JSON, MVP в виде одного portable `.exe` для Windows 11.

## 1. Визуализация JSON → интерактивный граф

Основа — переиспользование кода JSON Crack (`packages/jsoncrack-react`).

- Парсинг JSON/YAML/XML/CSV.
- Интерактивный граф: зум, панорамирование, раскрытие/сворачивание узлов.
- Тёмная/светлая тема.

*(Фаза 3 roadmap)*

## 2. Форматирование и валидация

- Форматирование ввода (pretty-print).
- Валидация с подсветкой ошибок.

*(Фаза 4, п. 4.1)*

## 3. Конвертация форматов

- Двусторонняя конвертация JSON ↔ YAML / CSV / XML.

*(Фаза 4, п. 4.2)*

## 4. Экспорт визуализации

- Экспорт графа в PNG / JPEG / SVG.

*(Фаза 4, п. 4.3; в п. 1.3 roadmap — PNG/SVG как минимум)*

## 5. Нативная интеграция (Tauri)

- Открытие/сохранение файлов через нативные диалоги.
- Drag-and-drop файлов в окно.
- Вся обработка данных локальна, без сети.

*(Фаза 5)*

## 6. Поставка

- Один portable `.exe` (`tauri build --no-bundle`), без внешних DLL/ресурсов.
- Целевая ОС: Windows 11 (WebView2 из системы). Win10 не поддерживается.

*(Фазы 6 и вводная часть roadmap)*
